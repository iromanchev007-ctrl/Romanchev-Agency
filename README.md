# Romanchev Flow — сайт

Одностраничный сайт на чистом HTML + CSS + JS. Без сборки и npm: откройте `index.html` двойным кликом — он работает так же, как на хостинге.

```
index.html    разметка и мета-теги для превью ссылки
config.js     весь контент и настройки   ← правьте здесь
styles.css    стили; цвета, шрифты, скругления — переменные в :root
main.js       подставляет контент из config.js в страницу
assets/       картинки
```

## Как поменять контент

Всё меняется в `config.js`: правите, сохраняете, обновляете страницу. HTML и CSS трогать не нужно.

| Что | Где в `config.js` |
| --- | --- |
| Название, слоган | `brand.name`, `brand.tagline` |
| Фото на первом экране | положите вертикальное фото 9:16 в `assets/` с именем `hero.jpg` — путь уже прописан в `brand.image`. Пока файла нет, на его месте градиентная заглушка. `""` — первый экран без фото |
| Эмблема | положите файл в `assets/`, например `logo.png` или `logo.svg`, и пропишите `brand.logo: "assets/logo.png"`. Она встанет рядом с названием в шапке и футере |
| Фавикон | `brand.favicon` |
| Цветовая тема | `theme.preset`: `"violet"`, `"green"` или `"orange"` |
| Свой акцентный цвет | `theme.accent: "#3b82f6"` (второй цвет для градиентов подберётся сам) |
| Шрифт | `theme.font`: название с [fonts.google.com](https://fonts.google.com), например `"Inter"` или `"Onest"`. Выбирайте шрифт с кириллицей |
| Услуги | массив `services` |
| Кейсы | массив `cases` |
| Блок «Разбор» | `cta`: заголовок, текст, 3 пункта, текст кнопки, ссылка. Кнопка на первом экране ведёт по той же ссылке |
| Контакты в футере | `contacts`. Пустые поля не показываются |

**Кейсы.** Добавить кейс — скопировать объект `{ ... }` целиком вместе с запятой после него и поменять тексты. Удалить — стереть объект. Любое поле можно оставить пустым `""`. Ссылка «Подробнее» под цитатой — поле `link`.

**Картинки кейсов.** Положите файл в `assets/`, например `assets/case-4k.jpg`, и пропишите в нужном кейсе `image: "assets/case-4k.jpg"`. Картинка показывается в горизонтальной рамке 2:1, лучше около 1200×600: вертикальная обрежется по краям. Без картинки или если файл не найден — градиентная заглушка.

Имена файлов пишите латиницей без пробелов и следите за регистром: на GitHub Pages и Vercel `Hero.JPG` и `hero.jpg` — разные файлы.

**Если страница стала пустой** — в `config.js` синтаксическая ошибка, обычно пропущенная запятая или кавычка. Откройте консоль браузера (F12 → Console), там будет номер строки.

## Превью ссылки в Telegram

Telegram и другие мессенджеры не выполняют JavaScript, поэтому `title`, `description` и Open Graph теги лежат прямо в начале `index.html`. **Меняйте их там**, а не в `config.js`:

- `<title>` и `description` — заголовок и описание;
- `og:title`, `og:description` — текст превью;
- `og:url`, `og:image` — полные адреса (`https://...`). После переезда на свой домен замените их;
- картинка превью — `assets/og-image.png`, 1200×630.

Telegram кэширует превью. Чтобы он увидел изменения, отправьте ссылку боту [@WebpageBot](https://t.me/WebpageBot).

Цвета фавикона заданы в самом `assets/favicon.svg` (и в `assets/apple-touch-icon.png`) и сами не меняются вместе с темой.

## Публикация на GitHub Pages

1. В репозитории на GitHub: **Settings → Pages**.
2. **Source:** Deploy from a branch. **Branch:** ветка с сайтом (обычно `main`), папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт откроется по адресу `https://iromanchev007-ctrl.github.io/Romanchev-Agency/`.

## Переезд на Vercel со своим доменом

1. На [vercel.com](https://vercel.com): **Add New → Project** → выберите этот репозиторий.
2. Framework Preset: **Other**, команду сборки не указывайте → **Deploy**.
3. **Settings → Domains** → добавьте купленный домен и пропишите DNS-записи, которые покажет Vercel.
4. В `index.html` замените `og:url` и `og:image` на адреса с новым доменом.
